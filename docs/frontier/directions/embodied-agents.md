# 具身智能（Embodied Agents）

> **维护约定**：「现状速览」每季度重写一次；新事件只往「时间线」和 `data/events.yml` 里追加。

## 现状速览

具身智能 = agent 的身体化：机器人通过视觉-语言-动作（VLA）模型直接从指令生成运动控制。2024-2026 路线明显收敛到 VLA 大一统（RT-2 → π0 → 各家开源 VLA），世界模型（从视频学习环境规律）作为其「想象力」补充。与数字 agent 相比，其独特约束是**物理世界的不可逆性与数据稀缺**——仿真到真实（sim2real）迁移依然是主要瓶颈。产品化集中在仓储物流（已规模化）、工业巡检、实验室自动化；家用机器人仍处于「demo 惊艳、可靠性不足」阶段。与知识库其他方向的关系：具身智能复用同一套 agent 概念栈（规划/记忆/工具调用），只是「工具」变成了身体，长期记忆与安全护栏的方法论可互相借鉴。

## 核心技术挑战

1. **数据稀缺**：机器人真机数据昂贵——遥操作采集、仿真合成、视频学习三条路线竞争。
2. **长程规划与错误恢复**：物理动作失败无法「重试免费」，恢复策略是核心。
3. **实时性**：控制回路毫秒级，与 LLM 推理延迟天然冲突——分层控制（快反射+慢思考）是主流架构。
4. **安全**：物理伤害不可逆，约束比数字 agent 严格一个量级。
