## 本周速览

- **[agentic-commerce] PayPal 全面接入 agentic commerce 支付标准**——agent 代付从协议试点走向规模商用，距 AP2 发布仅 14 个月。[来源](https://newsroom.paypal-corp.com/)
- **[skills] Agent Skills 跨工具生态成型**——1000+ skills 合集覆盖 Claude Code/Codex/Gemini CLI/Cursor，「agent 能力像 npm 包一样分发」成为现实。[awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)
- **[multi-agent] 多智能体标准化年收官**——A2A 与 AGNTCY 均入 Linux 基金会，75+ 组织参与 AGNTCY；企业跨组织 agent 互调开始有公共语言。[AGNTCY](https://github.com/agntcy)
- **[enterprise] Gartner：2026 年底 40% 企业应用将内置任务级 agent**（去年同期不足 10%）——从试点到生产的拐点已过。[Salesforce Agentic Enterprise Index](https://www.salesforce.com/news/stories/agentic-enterprise-index-insights-2026/)
- **[security] 间接提示注入被确认「已在野外」**——CSA 报告记录真实攻击，OWASP Agentic Top 10（2025-12）成为权威参考。[CSA](https://labs.cloudsecurityalliance.org/research/csa-research-note-indirect-prompt-injection-in-the-wild-2026/)
