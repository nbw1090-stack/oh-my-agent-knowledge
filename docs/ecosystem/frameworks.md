**选型速查**：

- 生产复杂工作流 / 需要细粒度控制 → **LangGraph**
- 多智能体快速起步 / 角色化分工 → **CrewAI**

- 类型安全优先 → **PydanticAI**；TS 全栈 → **Mastra**
- 检索密集型 → **LlamaIndex Workflows**
- 国内模型生态协同 → **Qwen-Agent / AutoGLM**
